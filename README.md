# 土地カルテ3D

公開データ（国土地理院・ハザードマップポータル）で日本の土地の良し悪しを3D地図で確認するWebアプリ。設計書は [docs/design.html](docs/design.html)。

## MVP でできること

- 地理院の標高タイルをブラウザ内で Terrain-RGB に変換し、MapLibre GL JS で3D地形表示（高さ強調 1〜3倍）
- 重ねるハザードマップ（洪水・高潮・津波・土砂災害警戒区域）と治水地形分類図の重ね合わせ
- 地点クリックで「土地カルテ」：標高、洪水/高潮/津波の浸水深ランク、土砂災害警戒区域の内外
- 住所検索（地理院 地名検索API）、URL で地点・レイヤー・視点を共有

ビルド不要の静的サイトです。GitHub Pages でそのまま配信できます。

## ローカル実行

```bash
python3 -m http.server 8765
```

http://localhost:8765 を開く。
