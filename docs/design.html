土地カルテ3D
公開データで見る、日本の土地の良し悪し

住所や地図上の1点を選ぶと、地形・川・雨・災害リスク・地価・都市計画を3D地図に重ねて表示し、その土地の「カルテ」を返すWebサイトの設計です。データはすべて国や公的機関が公開しているものを使います。

01概要

誰のための、何をするサイトか

想定ユーザー

  • 住宅購入・土地購入を検討する個人
  • 不動産会社の仕入れ・重要事項説明の下調べ
  • 自治体・防災関係者の説明資料

サイトの役割

  • 1地点の災害リスクと地形の成り立ちを一画面で把握
  • 3Dで「低い土地」「水が集まる土地」を直感的に見せる
  • 根拠データと出典を必ず併記する

やらないこと

  • 重要事項説明や公式ハザードマップの代替
  • 地価の将来予測（推移の表示まで）
  • 避難判断のリアルタイム指示

主要機能

  • 3D地形ビュー：地理院の標高データで地形を立ち上げ、航空写真・地図を貼る。高さ強調（1〜3倍）切替。
  • 川の流れ：河川ラインに沿って流れる方向をアニメーション表示。流域界と、選択地点がどの流域に属するかを表示。
  • 雨：直近の降水（ナウキャスト）の時間アニメーションと、雨量に応じた3D雨粒エフェクト。
  • ハザード重ね合わせ：洪水・内水・高潮・津波・土砂・液状化傾向を切替。洪水は浸水深を水面の高さとして3D表示。
  • 3D建物：PLATEAU整備都市では建物を立体表示し、浸水深と建物高さを比較できる。
  • 土地カルテ：地点クリックで、リスク項目ごとの評価・根拠・出典をまとめたパネルを表示。URLで共有可能。

02画面構成

地図が主役の1画面アプリ。右側に土地カルテ、左上にレイヤー操作、下部に時間スライダー。

操作フロー

  1. 住所検索（地理院のジオコーダ等）または地図クリックで地点を選ぶ
  2. カメラが地点へ斜め上空からフライし、地形と周辺の川を表示
  3. カルテAPIが地点の判定結果を返し、右パネルに表示。該当レイヤーが自動でONになる
  4. URL（/p/35.6812,139.7671 形式）で共有。同じ視点・レイヤーで開く

043D表現

描画エンジンの選定と、川・雨・浸水の見せ方

エンジン選定

案構成長所短所
A（推奨）MapLibre GL JS + deck.gl（MapboxOverlay）OSSで無料。地理院標高タイルを addProtocol でTerrain-RGBに変換して地形表示できる。ベクタータイル・PMTilesと相性が良い。モバイルで軽いPLATEAUの3D Tilesを地形と高さを合わせて載せる調整が必要
BCesiumJS3D Tilesがネイティブ。地球全体・大縮尺の3Dに強い。PLATEAU VIEWと同系統重い。地理院標高を quantized-mesh に変換するか別地形を用意する必要がある。2D的なUIは作りにくい

まずA案で作り、PLATEAU都市で建物表現をもっと作り込みたくなった段階で、建物詳細ビューだけCesiumに切り替える二段構えにします。

地形

  • 地理院の標高タイルは x = 2¹⁶R + 2⁸G + B、0.01m単位、無効値は (128,0,0) という独自形式。クライアント側で Terrain-RGB に変換する（既存OSS実装あり）。
  • 高さ強調は既定1.5倍。平野部の微地形（自然堤防・旧河道）を見せるため、5mメッシュがある地域では z15 まで使う。
  • 陰影起伏図と治水地形分類図を半透明で重ね、「水が集まる低い帯」を見やすくする。

川の流れ

  • 国土数値情報「河川」ラインを上流→下流の向きに正規化（始点・終点の標高で検証し、逆なら反転）。
  • deck.gl TripsLayer で線に沿って光の粒が流れる表現。河川の等級（一級・二級）で線幅と速度を変える。
  • 流域界ポリゴンを薄く表示。地点を選ぶと所属流域をハイライトし、「この雨はどの川に流れ込むか」を示す。
  • 発展案：DEMから流向（D8）を計算し、地点から下流への水の通り道を線で描く。

雨

  • 降水強度ラスタを時刻ごとに重ね、下部スライダーで過去3時間〜1時間先を再生。
  • 画面内の平均降水強度に応じて、パーティクルの雨粒の密度を変える演出（データの代わりではなく雰囲気づけ）。
  • 過去の大雨は「解析雨量」の積算値で振り返り表示（例：令和元年東日本台風の48時間雨量）。取得方法は規約確認後に決定。

浸水を水面として立ち上げる

洪水浸水想定のランク（浸水深）を、地面の標高に足した高さの半透明の水面として描きます。色は国の手引きに沿ったハザードマップ標準の段階色を使い、紙のハザードマップと見比べても違和感がないようにします。

水面高 = 地盤標高（DEM） + ランク代表値（0.25 / 1.75 / 4 / 7.5 / 15 / 20m）

  • 2階床上（約3m）・3階床上（約5.5m）の目安線を、PLATEAU建物の外壁に重ねて表示。
  • 地点カルテには「1階浸水」「2階まで浸水」など、生活に置き換えた言葉で出す。

05土地スコア

点数だけを見せず、項目ごとの根拠と出典を必ず並べる

各項目を0〜100で評価し、重みづけ平均で総合点を出します。重みはユーザーが変更できます（「子育て重視」「災害重視」などのプリセット）。初期値は次のとおり。

水害（洪水・内水・高潮・津波）30%
土砂災害15%
地盤・地形の成り立ち15%
地震の揺れやすさ15%
生活利便（駅・学校・医療）15%
地価の推移10%

水害想定最大規模の浸水深、浸水継続時間、家屋倒壊等氾濫想定区域、内水浸水想定、高潮・津波の浸水深国土数値情報、不動産情報ライブラリ防災API
土砂災害土砂災害警戒区域／特別警戒区域の内外、急傾斜地、地点周辺の傾斜量国土数値情報、標高タイル
地盤・成り立ち旧河道・後背湿地・埋立地・盛土などの地形分類、周辺との相対標高治水地形分類図・土地条件図、標高タイル

生活利便最寄り駅距離と乗降客数、小中学校区、医療機関、避難場所までの距離不動産情報ライブラリAPI、国土数値情報

表示ルール　ハザード区域外でも「リスクがない」とは書かない。「想定区域に含まれていない（想定の対象外の川や中小河川がある可能性）」と表現し、市町村のハザードマップへのリンクを添える。

フロントエンド

  • React（Vite）+ TypeScript
  • MapLibre GL JS v5、deck.gl
  • 状態はURLに同期（共有リンク）

バックエンド

  • PostGIS：ハザードポリゴン・地形分類・用途地域
  • カルテAPI：地点→判定JSON
  • 不動産情報ライブラリのAPIキーはサーバ側のみで保持

配信

  • 自前ベクタータイルはPMTiles 1ファイルにしてCDN配信
  • 地理院・ハザード・PLATEAUは各配信元から直接読む
  • ホスティング例：Cloudflare R2 + Workers、または AWS S3 + CloudFront + Lambda

08出典・利用規約

  • 重ねるハザードマップ：配信URLからリアルタイムに読み込み、商用・非商用を問わず利用可。出典は「ハザードマップポータルサイト」と記載し、ページへのリンクを付ける。
  • 地理院タイル：出典明示でリアルタイム表示は申請不要。ただしデータにより条件が異なり、加工して再配布する場合は測量法の承認が要るケースがあるため、タイルを加工保存する前に確認する。
  • 不動産情報ライブラリAPI：無料だが事前申請とAPIキーが必要。キーはフロントに置かない。
  • PLATEAU：商用利用を含め無償で利用可。出典表記を行う。
  • 気象庁の降水タイル：Webページ表示用のタイルで、開発者向けに保証された公式APIではない。URL変更で止まる前提で作り、商用運用やリアルタイム配信を主機能にする段階では気象業務支援センター経由の正式データ取得を検討する。
  • 市町村のハザードマップ（わがまちハザードマップ）は自治体ごとに規約が違うので、リンクのみとする。
免責表示　画面下部とカルテ末尾に「本サイトは公開データを重ねて表示したもので、公式のハザードマップや重要事項説明に代わるものではありません」と常時表示する。

09開発フェーズ

  1. MVP（約6週間）：対象を1都県（例：東京都）に限定。3D地形＋重ねるハザードマップ表示＋洪水・土砂の地点判定＋カルテパネル＋共有URL。
  2. フェーズ2：全国の国土数値情報を取り込み。川の流れアニメーション、流域表示、治水地形分類、地価推移、不動産情報ライブラリ連携。
  3. フェーズ3：PLATEAU建物と浸水水面の3D比較、雨のタイムライン、J-SHIS地震、スコアの重み調整、2地点比較。
  4. フェーズ4：PDFカルテ出力（サーバ生成）、物件リストの一括判定API、自治体ごとのデータ更新監視。

10リスクと対策

リスク対策
データの更新時期がばらばら（数年前の想定が混在）dataset_version で各データの時点を管理し、カルテに表示する
地図表示とAPIの結果が食い違う（原典の違い）判定は国土数値情報に統一し、表示タイルとの差がありうる旨を注記
「区域外＝安全」という誤解表現ルール（05章）を守り、中小河川や内水の想定未整備地域を明示
外部タイルの配信停止・URL変更レイヤー単位で読み込み失敗を検知し、該当レイヤーだけ「現在取得できません」と表示
モバイルでの3D描画負荷端末性能で建物LODと雨パーティクルを自動で間引く。2D表示への切替ボタン
国土数値情報の全国データ量PMTilesで配信し、PostGISはズーム不要の判定専用に簡略化ジオメトリを持つ
